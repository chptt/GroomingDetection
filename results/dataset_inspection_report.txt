## 10. PAPER REPRODUCIBILITY ASSESSMENT
================================================================================

### What CAN be reproduced:

✓ Message-Level Analysis (MLA) for Adult vs. Child classification
  - Each line is an utterance from a known speaker (predator=Adult, officer=Child)
  - Train SVM, NB, BERT, RoBERTa to classify individual messages
  - Metrics: TP, IA (Incorrect Adult), IC (Incorrect Child), O (Omissions)
  - Message Threshold (t) omission: Eq. (1) from paper applies

✓ Context Determination per conversation
  - Aggregate per-actor message predictions using binomial test
  - Actor Significance Threshold (AST) p-value test
  - Transcript-level Adult-Child (AC) context determination
  - Metrics: TP, FP, TN, FN, F1 for detecting AC interactions

✓ Group-based train/test splits (80/20 by conversation, not message)

### What CANNOT be reproduced exactly:

✗ Phase-based analysis (O'Connell 2003 grooming stages)
  - Requires chronological message order, which is not preserved

✗ Turn-level or sequential context features
  - Cannot measure response times, turn-taking patterns, or topic shifts

✗ Early detection experiments
  - Requires progressive message disclosure in original order

### Important clarifications:

• Speaker role ≠ Message-level grooming label
  - Predator utterances are from adults, but not every message is 'grooming'
  - Officer utterances are from honeypot actors, not real children
  - MLA classifies Adult vs. Child language, NOT grooming vs. non-grooming

• Context Determination determines if conversation involves Adult+Child
  - All PJ transcripts are OG-positive by design (no true negatives)
  - Cross-dataset evaluation (PAN12) provides negative examples

• No ground-truth per-message grooming labels exist in this dataset
